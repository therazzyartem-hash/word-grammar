# Корректор — проверка текста для Word Online

Панель справа в Word. Пока пишешь, проверяет каждый дописанный абзац (через бесплатный LanguageTool),
показывает число ошибок по абзацам и исправляет всё одной кнопкой.

- **Исправить все** — правит все ошибки, у которых есть вариант исправления.
- **Исправить** у абзаца — только этот абзац. Клик по карточке — список ошибок с вариантами.
- Слова с заглавной в середине предложения (имена) сами не правятся — только показываются.
  Кнопка **В словарь** — больше не считать слово ошибкой (словарь хранится в самом документе).
- В настройках можно включить **режим исправлений** — каждая правка будет видна и её можно отклонить.

## 1. Выложить на GitHub Pages (один раз, бесплатно)

1. Создать на github.com публичный репозиторий `word-grammar`.
2. Загрузить в него все файлы этой папки (`Add file → Upload files`).
3. `Settings → Pages → Branch: main, / (root) → Save`. Через минуту сайт будет по адресу
   `https://ИМЯ.github.io/word-grammar/`.
4. В `manifest.xml` заменить все `BASE_URL` на `https://ИМЯ.github.io/word-grammar` (без `/` в конце)
   и загрузить исправленный файл снова.

## 2. Подключить в Word Online (другу, один раз)

1. Открыть документ в Word Online.
2. `Главная → Надстройки → Дополнительные надстройки → Мои надстройки → Отправить мою надстройку`
   (в некоторых версиях: `Вставка → Надстройки → Загрузить мою надстройку`).
3. Выбрать файл `manifest.xml` → **Отправить**.
4. На вкладке «Главная» появится кнопка **Проверка текста**. Панель дальше открывается с документом сама.

## Проверка без Word

`test.html` — стенд с имитацией Word: `python -m http.server 8765` и открыть `http://localhost:8765/test.html`.

## Ограничения

- Пунктуацию проверяют LanguageTool и свои правила (`punctuation.js`): запятые перед «что», «чтобы», «который»,
  «потому что», «хотя», «будто», «если», вводные слова в начале предложения, пробелы у знаков, тире в диалогах,
  точка в конце абзаца, закрывающая запятая после «который…», деепричастные и причастные обороты.
  Обороты распознаются по окончаниям слов, без настоящего разбора предложения. Если граница оборота неясна
  («Вернувшись домой мама легла» — где кончается оборот?), ошибка показывается, но «Исправить все» её не трогает.
  Однородные члены, обращения и запятые между частями сложного предложения пока не ловятся.
- `tests.html` — тесты пунктуации (открыть так же, как `test.html`). Гонять после любой правки `punctuation.js`.
- Лимит ~20 запросов в минуту: первую проверку большой книги делает несколько минут, дальше — мгновенно.
- Текст абзацев отправляется на сервер LanguageTool (languagetool.org) для проверки.
